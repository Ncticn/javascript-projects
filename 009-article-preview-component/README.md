# 📌 Article Preview Component

This project is a solution to the "Article Preview Component" challenge on Frontend Mentor.

The challenge focuses on building a responsive article preview component using HTML, CSS, and JavaScript. The goal was to reproduce the provided design as closely as possible while ensuring the component adapts appropriately to different screen sizes and includes the required interactive sharing functionality.


## 🖼️ Preview

![Project Preview](./previews/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive article preview component
- Structuring the component using semantic HTML elements
- Creating responsive layouts for different device screen sizes
- Reproducing the provided mobile and desktop layouts
- Implementing the share functionality using JavaScript
- Displaying social media share links when the share icon is clicked
- Implementing hover states for interactive elements
- Styling buttons, icons, and interactive elements to match the provided design
- Applying the provided colors, typography, spacing, and visual hierarchy
- Reproducing the provided design as closely as possible
- Ensuring the layout shifts appropriately across different screen sizes



## 🧠 What I Learned

Through this project, I practiced:

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 009-article-preview-component

# Install dependencies
npm install

# Start the development server
npm run dev
```
