# 📌 Testimonials Grid Section

This project is a solution to the "Testimonials Grid Section" challenge on Frontend Mentor.

The challenge focuses on building a responsive testimonials grid section using HTML and CSS. The goal was to reproduce the provided design as closely as possible while ensuring the layout adapts appropriately to different screen sizes.

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 007-testimonials-grid-section

# Install dependencies
npm install

# Start the development server
npm run dev
```
