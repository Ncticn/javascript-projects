# 📌 Social Links Profile

This project is a solution to the "Social Links Profile" challenge on Frontend Mentor.

The challenge focuses on building a responsive social links profile where users can showcase and share their social media profiles. The goal was to reproduce the provided design as closely as possible while practicing layout, typography, spacing, and interactive states with HTML and CSS.


## 🖼️ Preview

![Project Preview](./previews/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive social links profile layout
- Building the page structure using semantic HTML
- Displaying a profile section with user information
- Creating social media and profile links
- Styling the profile card to match the provided design
- Applying the provided colors, typography, spacing, and visual hierarchy
- Implementing hover and focus states for all interactive elements
- Reproducing the provided mobile and desktop layouts
- Matching the provided design as closely as possible


## 🧠 What I Learned

Through this project, I practiced:

- Structuring web pages with semantic HTML
- Creating reusable and accessible interactive links
- Implementing hover and focus states for interactive elements
- Creating responsive layouts with CSS
- Working with typography, colors, spacing, and visual hierarchy
- Building a clean profile card component
- Translating a provided design into a functional web interface
- Improving attention to detail when reproducing a professional UI design


## 🛠️ Tech Stack & Concepts

- **Markup:** Semantic HTML

- **Responsive Design:** Mobile, tablet & desktop layouts

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 003-social-links-profile

# Install dependencies
npm install

# Start the development server
npm run dev
```
