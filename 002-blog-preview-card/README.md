# 📌 Blog Preview Card

This project is a solution to the "Blog Preview Card" challenge on Frontend Mentor.

The challenge focuses on building a responsive blog preview card using HTML and CSS while practicing fundamental concepts such as HTML structure, the CSS box model, responsive layouts, and interactive states.

## 🖼️ Preview

![Project Preview](./previews/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive blog preview card layout
- Building the page structure using semantic HTML
- Styling the card using CSS
- Applying the provided design system, including colors and typography
- Reproducing the provided mobile, tablet, and desktop layouts
- Implementing hover and focus states for interactive elements
- Practicing the CSS box model and fundamental layout techniques
- Matching the provided design as closely as possible


## 🧠 What I Learned

Through this project, I practiced:

- Structuring web pages with semantic HTML
- Understanding and applying the CSS box model
- Creating responsive layouts with CSS
- Working with typography, colors, spacing, and visual hierarchy
- Implementing hover and focus states for interactive elements
- Translating a provided design into a functional web interface
- Improving attention to detail when reproducing a professional UI design


## 🛠️ Tech Stack & Concepts

- **Markup:** Semantic HTML
- **Styling:** CSS
- **Responsive Design:** Mobile, tablet & desktop layouts
- **Layout:** CSS Box Model & Flexbox
- **Code Formatting:** Prettier

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 002-blog-preview-card

# Install dependencies
npm install

# Start the development server
npm run dev
```
