# 📌 QR Code Component

This project is a solution to the "QR Code Component" challenge on Frontend Mentor.

The challenge focuses on building a simple QR code component using HTML and CSS while practicing fundamental concepts such as HTML structure, the CSS box model, typography, spacing, and visual hierarchy.

## 🖼️ Preview

![Project Preview](./previews/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a QR code component layout
- Building the page structure using semantic HTML
- Styling the component using CSS
- Applying the provided design system, including colors and typography
- Reproducing the provided design as closely as possible
- Practicing the CSS box model and fundamental layout techniques
- Working with spacing, sizing, and visual hierarchy
- Creating a clean and simple user interface


## 🧠 What I Learned

Through this project, I practiced:

- Structuring web pages with semantic HTML
- Understanding and applying the CSS box model
- Working with typography, colors, spacing, and visual hierarchy
- Creating and styling reusable UI components
- Translating a provided design into a functional web interface
- Improving attention to detail when reproducing a professional UI design
- Building a simple component without relying on complex responsive layout techniques



## 🛠️ Tech Stack & Concepts

- **Markup:** Semantic HTML
- **Styling:** CSS
- **Responsive Design:** Mobile, tablet & desktop layouts
- **Layout:** CSS Box Model & Flexbox
- **Code Formatting:** Prettier
- **Version Control:** Git & GitHub

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 001-qr-code-component

# Install dependencies
npm install

# Start the development server
npm run dev
```
