# 📌 Four Card Feature Section

This project is a solution to the "Four Card Feature Section" challenge on Frontend Mentor.

The challenge focuses on building a responsive four-card feature section using HTML and CSS. The goal was to reproduce the provided design as closely as possible while ensuring the layout adapts appropriately to different screen sizes.


## 🖼️ Preview

![Project Preview](./previews/preview.jpg)

## 🎯 Overview

Through this project, I practiced and learned:

- Understanding and using CSS Grid to create structured grid-based layouts
- Using Flexbox to build flexible and responsive layouts
- Building the project from scratch with a mobile-first approach
- Experimenting with CSS ::before and ::after pseudo-elements
- Using the CSS :nth-child() pseudo-class to target specific elements
- Adding and using custom fonts from Google Fonts
- Understanding and applying CSS box-shadow to create depth and visual hierarchy


## 🧠 What I Learned

Through this project, I practiced:

- Structuring components with semantic HTML
- Creating multi-column layouts with CSS
- Creating responsive layouts with CSS
- Working with typography, colors, spacing, and visual hierarchy
- Creating layouts that adapt to different screen sizes
- Translating a provided design into a functional web interface
- Understanding how to organize multiple cards within a responsive layout
- Paying closer attention to visual details when reproducing a professional UI design

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/javascript-projects.git

# Navigate to the project directory
cd 006-four-card-feature-section

# Install dependencies
npm install

# Start the development server
npm run dev
```
